# nmoonfox Desktop

デスクトップ上で、月のきつねたちが気ままに過ごすWindows用アプリです。ChatGPTを開いていなくても動きます。

**[Windows版ZIPをダウンロード](https://github.com/Noon-R/nmoonfox-desktop/releases/latest/download/nmoonfox-desktop-win-x64.zip)** · **[リリース一覧](https://github.com/Noon-R/nmoonfox-desktop/releases)**

![nmoonfox Desktopの設定画面](https://raw.githubusercontent.com/Noon-R/nmoonfox-desktop/main/docs/settings.png)

## 起動方法

1. 上のリンクから `nmoonfox-desktop-win-x64.zip` をダウンロードし、好きなフォルダーへ展開します。
2. `nmoonfox-desktop.exe` をダブルクリックします。
3. 設定画面で表示数・大きさ・おさんぽの速さを調整してください。

Windows 10/11の64bit（x64）向けです。配布版は.NETを内蔵しており、追加インストールは不要です。複数ディスプレイに対応しています。

## できること

| 操作・設定 | 動作 |
| --- | --- |
| 表示数 | 0〜12匹。初期値は3匹 |
| すべてのディスプレイに表示 | オンなら各画面に分散。オフならメイン画面だけ。表示数は全画面の合計 |
| 大きさ | 横幅96〜240 DIP。初期値144 |
| おさんぽの速さ | 20〜140 DIP/秒 |
| 自動のおさんぽ | 歩く・休む・手を振る・周りを見る・考える・眠る |
| 画面全体をおさんぽ | オフなら画面下部、オンなら画面全体を移動 |
| マウスを乗せる | 接地したまま喜び、小さなハートが出る |
| 近くでマウスを素早く往復させる | 起きている子が早足で道を空ける。退避中はクリックが通り、数秒待ってから通常のおさんぽに戻る |
| ドラッグ | ふわっと浮いて、傾いたり揺れたりしながら移動。別の画面にも連れていけます。離すとにっこり |
| 右クリック | なでる・設定・呼び戻す・1匹を表示から外す |
| みんなでお昼寝 / 起こす | 眠る姿とゆっくりした呼吸 / 起床 |
| ひとやすみ | 自律動作を一時停止。もう一度押すと再開 |
| クリックを通す | ペット越しに下のアプリを操作。解除は設定かトレイから |
| この画面に集める | 操作した画面の下部に全員を集める（メイン画面限定の設定時はメイン画面へ） |
| 各画面に分ける | 全員を各ディスプレイの下部に分けて配置 |

設定画面の×を押すと画面だけ閉じ、ペットは動き続けます。画面右下のタスクトレイ（隠れている場合は「^」）にある月のアイコンをダブルクリックすると設定を開けます。終了するには、設定画面の「アプリを終了」かトレイの「終了」を選びます。

0匹にした場合やクリック透過を有効にした場合も、トレイから設定を開けます。同じアプリを再度起動しても、ペットが重複起動することはありません。

### 作業の邪魔になったら

ペットの近くでマウスを左右か上下に、素早く2往復ほど振ってください。近くの起きている子だけが離れ、退避開始から約6秒は反応を控えます。画面端では逃げられる方向へ移動します。画面下部モードでも、退避時だけ上へ移動することがあります。

ゆっくりした移動や一方向への移動では退避しません。ドラッグなどのマウスボタン押下中、設定画面の操作中、ひとやすみ中、お昼寝中は反応しません。「マウスを振ると、近くの子が道を空ける」でオフにできます（初期値オン）。

### 複数ディスプレイで使う

「すべてのディスプレイに表示」は初期値オンです。起動時に表示数を各画面へ分けます。3匹なら3画面まで1匹ずつ、画面数より少ない場合は表示数を増やしてください。画面を追加した後は「各画面に分ける」で配置し直せます。

画面間の移動はドラッグで行います。自動のおさんぽとマウスからの退避は、その子がいる画面の作業領域内で動きます。画面間の空白へ歩いて見失うことはありません。左右・上下・負座標の配置に対応し、タスクバーを避け、各画面のWindows拡大率に合わせてサイズと速度を調整します。

ディスプレイを取り外すと、その画面の子を残った画面へ戻します。配置・解像度・拡大率の変更も反映します（通常すぐ、検知の補完は約2秒ごと）。ひとやすみ中もドラッグ中の表情と揺れは動きます。

更新する場合は、起動中の旧版をトレイの「終了」で閉じ、新しいZIPを展開して起動してください。保存済みの表示数やサイズなどは引き継ぎます。

## データと描画

- 設定は `%LOCALAPPDATA%\nmoonfox-desktop\settings.json` に自動保存します。表示数・サイズ・速度・全ディスプレイ表示・最前面・移動範囲・クリック透過・マウスを振った際の退避が保存対象です。
- お昼寝・一時停止・各個体の一時的な位置は再起動でリセットします。
- 自動起動、ネットワーク通信、テレメトリーはありません。
- ペット用アトラスは192×208pxのセルを維持。なでられ行はジャンプに変更していません。
- お昼寝には別途制作した透過イラストを使用し、呼吸・歩行時の小さな上下動・ハートを組み合わせています。
- 大きく表示すると、既存スプライトの解像度による柔らかさがあります。

配布版は未署名です。排他フルスクリーンのゲーム上への表示は対応範囲に含めていません。複数画面・異なるDPIの組合せはCoreで自動検証し、実ウィンドウの確認は1画面・100%環境で実施しています。複数の実機ディスプレイでの操作感は未確認です。

## 開発

.NET 10 SDK（global.jsonの指定に対応するバージョン）とWindowsが必要です。追加NuGetライブラリは使っていません。

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
powershell -ExecutionPolicy Bypass -File scripts/publish.ps1
```

`artifacts/nmoonfox-desktop-0.3.0-win-x64/`（バージョン別）に実行ファイル、`artifacts/nmoonfox-desktop-win-x64.zip` に配布ZIPが作成されます。旧版を実行中でも新版を作れるよう、出力先を分けています。初回publishでは.NETの配布ランタイムを取得します。

GUIの自動確認には、ユーザーの設定を使わない専用フォルダーを指定できます。テストは自動終了します。

```powershell
.\artifacts\nmoonfox-desktop-0.3.0-win-x64\nmoonfox-desktop.exe --smoke-test C:\path\to\isolated-smoke-output
```

設計は `docs/design.md`、検証結果は `docs/verification.md`、Coreの独立検証は `docs/core-verification.md` を参照してください。
