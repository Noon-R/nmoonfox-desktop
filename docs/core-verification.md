# Core 独立検証

## 0.3.0（2026-10-23）

既存19項目と、独立エージェントが追加した複数画面/ドラッグ16項目が全件成功。コンソールは16項目を1グループにまとめて **20/20 passed** と表示する。負座標、上下/L字/隙間、100/150/200%倍率、DPIに応じた速度と寸法、画面間ドラッグのつかみ位置、Gather/Spread、メイン限定、並び順変更、同ID移設、切断回復、極小画面、退避、永続化を検証。12匹×10分相当×2モードで全身が実在する画面の作業領域内に留まることも確認。

ドラッグの時計/表情が進んでも自律移動しないこと、休憩中は他の個体が静止すること、傾きの左右反転・上限・減衰・DPI間の一致、離すと喜ぶ反応へ戻ることを確認。実機GUIの確認範囲は verification.md を参照。

以下は初版の検証記録。

2026-10-22、実装担当と別の検証エージェントが `docs/design.md` の公開契約を基にコンソールテストを作成した。外部 NuGet テストランナーは不要で、失敗時は終了コード 1 を返す。

```powershell
$env:MSBuildEnableWorkloadResolver='false'
$env:DOTNET_CLI_HOME=Join-Path (Get-Location) 'artifacts/dotnet-home'
$env:DOTNET_CLI_TELEMETRY_OPTOUT='1'
dotnet run --project tests/Nmoonfox.Core.Tests -c Release
```

結果: **13/13 passed**、終了コード 0。

- 設定初期値、範囲外値・NaN・Infinity の正規化。
- 0〜12 匹、個体 ID とオブジェクトの独立、削除と設定数の整合、無効 ID 操作。
- 同一 seed と入力の再現性。
- 30fps と 60fps で同じ 12 秒を進めた際の状態・座標・時計一致。
- 無効 delta の無視、巨大 delta が短時間で安全に処理されること。
- 休憩中の位置・状態・反応時計の凍結と再開。
- 作業領域へのクランプ、サイズ変更、負座標ディスプレイ、ペットより狭い画面、無効 bounds の正規化。
- なでられ反応中の連続呼び出しでアニメーションとハートが延長されないこと。
- ドラッグ中の自律移動停止、座標クランプ、無効座標の無視、離した時の喜び。
- 明示的なお昼寝の維持と一括起床。
- 全状態のセル範囲と長時間シミュレーション中のフレーム・視線番号の範囲。
- ポインターの右・上・左・下の数学的方位（0・4・8・12）と無効入力。
- 設定の保存・上書き・復元、破損 JSON・null、範囲外設定、保存時正規化、保存後の一時ファイル掃除。

位置はウィンドウ左上、幅は Size、高さは Size × 208 / 192 + 24 として検証する。作業領域がペットより狭い場合は左上に寄せる。実装の固定 1/60 秒ステップに合わせ、30/60fps 比較は位置誤差 1e-8 以下、時計誤差 1e-9 以下で確認した。

設定テストはプロジェクト配下の `artifacts/core-test-data` に一時ディレクトリを作成し、テスト終了時に削除する。Windows の一時フォルダでは sandbox のファイル置換制限が発生したため、ユーザーの本番設定を使わずこの隔離先を利用している。

この結果は純粋な Core の検証であり、WPF の透明領域クリック透過、実デスクトップのドラッグやフォーカス維持、トレイ、DPI 変更、配布実行ファイルの確認を代替しない。

## 0.2 マウスを振って退避（2026-10-23）

別の検証エージェントが6項目と永続化の検査を追加し、最終 **19/19 passed**。自然な減速を含む切り返し、30/60Hzのsin状の揺れを認識。静止・一方向・低速・微振動・ワープ・無効入力を除外。近接判定、なでられ状態からの退避、四隅（内側斜めの逃げ道を含む）、画面内制限、6秒の抑制、明示操作による取消、旧JSONへの既定値true適用を確認。

最初に検出された「切り返し時の一瞬の減速で履歴が途切れる」問題を修正して再検証。CoreとDesktopの検出連携・5種類のマウスボタン押下除外・一時クリック透過もコードレビューし、追加のブロッカーなし。実マウス操作と複数DPIは未検証。
